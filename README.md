## How these bots are built

- **One job each.** Every bot has a single goal and a written list of things it never does.
- **Human approval.** Sending, paying, signing and submitting wait for a yes.
- **Routines.** Scheduled runs (every 15 minutes to weekly) do the repeat work.
- **A record.** Google Sheets hold the pipeline; screenshots back up claims.
- **Tools.** Grok Bot, browser automation, Gmail, Google Sheets, Cursor coding agents, GitHub.
